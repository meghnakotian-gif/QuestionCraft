# QuestionCraft

AI-Assisted Exam Question Bank and Automated Paper Generation System

---

## 📌 Project Overview

QuestionCraft is an AI-powered web application designed to help educational institutions manage question banks and automatically generate balanced exam papers efficiently.

The system allows faculty to:
- Store and manage questions
- Generate exam papers automatically
- Conduct student exams
- Calculate scores automatically
- Analyze student performance

---

## 🚀 Features

- Faculty & Student Login
- Role-Based Authentication
- Question Bank Management
- MCQ Support
- Automatic Paper Generation
- Difficulty-Based Question Selection
- Automated Scoring System
- Student Score History
- Analytics Dashboard
